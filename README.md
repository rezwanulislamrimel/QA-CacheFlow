# QA CacheFlow

**Clean. Reload. Retest.**

QA CacheFlow is a Chrome extension designed to help Software QA Engineers clear website-specific cache and speed up repetitive browser testing workflows.

## Features

- Clear cache for the current website.
- Reload the page after clearing cache.
- Manage saved testing environments.
- Selectively clear supported website data.
- Preserve login sessions when using cache-only cleanup.
- Lightweight interface designed for QA workflows.

## Use Cases

- Testing web applications in development and staging environments.
- Troubleshooting stale CSS, JavaScript, and cached assets.
- Reproducing issues with fresh browser cache.
- Reducing repetitive manual browser operations.

## Installation

1. Clone or download this repository.
2. Open `chrome://extensions/` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the extension's project folder.

## Technology

- JavaScript
- HTML
- CSS
- Chrome Extensions Manifest V3

## Privacy

Website data cleanup is performed locally through supported browser APIs. Review the permissions and implementation before installing.
