## 📌 Overview

**QA CacheFlow** is a lightweight Chrome extension built specifically for **Software QA Engineers** — designed to clear website-specific cache and speed up repetitive browser testing workflows.

Stop wasting time manually navigating browser settings. One click to clear, reload, and retest.

```
Clear Cache ──▶ Reload Page ──▶ Retest ──▶ Done ✓
```

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🧹 **Clear Site Cache** | Clear cache for the current website only — not the entire browser |
| 🔄 **Auto Reload** | Automatically reload the page after clearing cache |
| 🌐 **Environment Manager** | Save and manage testing environments for quick switching |
| ⚙️ **Selective Cleanup** | Choose which types of website data to clear |
| 🔐 **Preserve Sessions** | Keep login sessions intact when using cache-only cleanup |
| ⚡ **Lightweight UI** | Minimal, fast interface built for QA workflows |

---

## 🎯 Use Cases

- 🧪 Testing web applications in **development and staging** environments
- 🐛 Troubleshooting **stale CSS, JavaScript, and cached assets**
- 🔁 Reproducing bugs with a **fresh browser cache**
- ⏱️ Reducing **repetitive manual browser operations** during test cycles

## 🚀 Installation

<details>
<summary><b>Install as Unpacked Extension (Developer Mode)</b></summary>

<br/>

```bash
# Step 1 — Clone the repository
git clone https://github.com/rezwanulislamrimel/qa-cacheflow.git
cd qa-cacheflow
```

1. Open **Chrome** and navigate to `chrome://extensions/`
2. Enable **Developer mode** (toggle — top right)
3. Click **Load unpacked**
4. Select the extension's project folder
5. **QA CacheFlow** will appear in your extensions list

> 📌 Pin the extension to your toolbar for quick access during testing sessions.

</details>

---

## 🔐 Privacy

Website data cleanup is performed **locally** through supported Chrome browser APIs.

- ✅ No data is sent to any external server
- ✅ All operations run entirely in the browser
- ✅ Only the current site's data is affected (not full browser cache)

> Review the permissions and implementation in `manifest.json` before installing.
